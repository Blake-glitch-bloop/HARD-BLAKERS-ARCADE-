# Brandon's Task Grabber

A neon claw-machine arcade game that chooses a task when indecision strikes.

Open `index.html` in a browser to play. Move the claw with the on-screen controls or arrow keys, then press **Drop** (or the spacebar) to grab a randomized task. Custom tasks are saved in the browser.

Completing a task earns 50 points and unlocks a motivational quote. Points can be spent on claw skins in the shelf store. Consecutive daily visits grant escalating bonuses, with the two-task Glo-Claw unlocking on day seven.

Built with only HTML, CSS, and JavaScript.
